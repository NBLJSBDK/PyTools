# file-dedup

按内容查找重复文件：先按大小分组，再对同尺寸文件算 MD5，最后让你确认后把重复项**移动**到回收目录。

## 运行

**只用标准库**，不需要虚拟环境：

```powershell
cd D:\PyTools\file-dedup
python find-duplicates.py
```

运行后按提示输入要扫描的路径，脚本会逐个询问确认。

## 环境

只用标准库，**不需要任何环境**，直接运行即可。若你习惯统一用虚拟环境，也可以用仓库根目录的 `.venv`：

```powershell
D:\PyTools\.venv\Scripts\python.exe 脚本名.py
```

## 说明

- 重复文件是**移动**，不是删除；确认前不会动任何文件。
- 目录路径为空时直接回车会退出。
- 同尺寸文件才会进入哈希比较，所以大目录也很快。
